What is represented

A small protocol, visible step by step.

The local implementation uses TCP sockets and a POSIX worker pool. An authenticated client reports its version and resume offset; the server either closes an up-to-date connection or streams the remaining package bytes.

  • 01 / AUTHToken accepted or rejected
  • 02 / VERSIONCompare client and latest versions
  • 03 / VERIFYResume transfer and compare MD5
